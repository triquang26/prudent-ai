When is an AI right-sizing decision even answerable from the evidence?

APT (Evidence-Decidability of AI Deployment Right-Sizing) turns a question every model-selection system silently answers — what is the smallest sufficient configuration? — into a decidability measurement, proves that today's leaderboard rules answer it wrong, and gives a selective procedure that knows when to abstain and names what to measure next.

We flip the prior question. The field spends its effort making the estimate of each axis sharper. We ask instead whether the deployment decision is identified at all from the evidence that exists — whether any configuration is certifiably minimum-sufficient, or whether a single missing axis could flip the answer no matter how the present axes are sharpened.

The reframe

Estimate-quality is the wrong frontier

Holistic benchmarks, cost-aware agent harnesses, LLM-judge reliability, routing and cascades — all of it sharpens the belief about each axis. The tacit prior is that a sharper belief yields a better deployment decision. But sharpness is useless if the decision was never identifiable to begin with.

The leaderboard prior — “make the estimate better”

Rank configs by an objective the practitioner already observes (accuracy, or accuracy/cost). Treat a missing axis as either absent or imputable. Answer anyway.

  • observed-Pareto (B2) commits a blind config every time
  • impute the median (B3) commits the identical blind config
  • cost-accuracy frontier (B6) drops latency / energy / governance
  • None of them can see that governance is unmeasured — so they ship it anyway
The APT prior — “is the decision identified?”

A query is evidence-decidable iff some configuration is provably feasible and provably minimum-sufficient — its argmin cost invariant across every completion of the missing or straddling cells.

  • COMMIT the identified min-sufficient config when decidable
  • ABSTAIN informatively — return the blocking axes + a VoI plan
  • INFEASIBLE when no completion can satisfy the query
  • ⊥ stays ⊥ — never impute a missing axis (constraint C1/C7)

The hook in one sentence: the evidence we have does not just leave right-sizing imprecise; it leaves right-sizing underdetermined — not identifiable from the evidence, no matter how the present axes are sharpened.

Three decidability states & the VoI identity

A query resolves to exactly one of three states under evidence corpus $E$:

  • DECIDABLE → a config is provably feasible & minimum-sufficient → COMMIT
  • UNDERDETERMINED → a missing axis could flip the optimum → ABSTAIN + name it
  • INFEASIBLE → no completion satisfies the query → INFEASIBLE

Acquisition is principled, not heuristic. The implemented Value-of-Information of an omitted binding axis $a^*$ equals the irreducible regret of the regime that omits it:

$$\mathrm{VoI}(a^*) \;=\; \Delta(R) \;=\; \frac{\delta\lambda}{\delta+\lambda}$$

Proven exact on the two-world gadget to rel_tol = 1e-9 over four $(\delta,\lambda)$ points (max gap 8.7e-19). It ties the acquisition signal to a limit theorem: no regime-restricted rule can drive expected regret below $\Delta(R)$ when the binding axis lies outside the regime.

The active-constraint binding test (W1). Axis $a$ binds at query $q$ iff removing it strictly lowers the optimal cost: min_cost(q without a) < min_cost(q). This is a per-instance Pareto certificate, not a declared tag — and it is what makes C2's mis-sizing claim land on truly binding axes. Measured agreement bite ⟺ binding = 1.000 over 544 queries (287 bind&bite, 257 non-bind&no-bite, 0 off-diagonal).

Side-by-side · real procedure, real substrate

What the two approaches actually do on one query

A practitioner needs a config for a medical-QA task that must satisfy quality ≥ 0.8 and governance ≥ 0.8 (an in-house-only deployment policy). The substrate has rich quality evidence — and zero governance evidence anywhere. Here is the divergence, run through the same C7 interface.

Leaderboard rule (observed-Pareto / impute)

Sees quality, doesn't see governance, treats ⊥ as “fine”. Picks the cheapest config clearing the quality bar and ships it.

decision = COMMIT
config   = cheapest-quality-feasible
governance = ⊥  (assumed OK)
→ 57.1% of such commits silently violate the hidden constraint

APT selective procedure (right_size)

A completion of the ⊥ governance cell could flip feasibility → the decision is not identified. It abstains and tells you exactly what to measure.

decision    = ABSTAIN
blocking_axes = ['governance']
voi_plan    = measure governance  (VoI = 1.0)
→ 0% hidden violation; the one field worth measuring is named

The same procedure on three live substrate queries

Run against the frozen apt_substrate.db (20 sources). These are the literal returns of right_size() — input query on the left, decision on the right.

This is the “informative abstention”: ABSTAIN is not a mute refusal — it returns the blocking axes and a cost-aware, VoI-ranked acquisition plan naming the single field worth measuring next.

§11 limit theorem · closure characterization

The theory behind the abstention

The acquisition signal is not a heuristic — it is tied to a closure characterization of decidability and a limit theorem on regret. Authored as a rigorous proof and adversarially verified.

What is proven

  • Lemma 1. $\mathrm{cl}(R)$ — the certifiable closure of a regime — is a genuine closure operator (extensive, monotone, idempotent). Unconditional.
  • Lemma 2. Monotone maps certify one-sided thresholds (≤ / ≥) but never a non-degenerate equality — the subtlety pinned.
  • Characterization. $q$ decidable $\iff \mathrm{Bind}^*(q) \subseteq \mathrm{cl}(R)$ for multi-axis binding under the value / active-constraint reading. (⇐ unconditional; ⇒ under structural regularity.)
  • Limit theorem. For cl(R)-restricted rules, $\Delta(R)$ is the irreducible residual after closure.
  • VoI corollary. $\mathrm{VoI}(a^*) = \Delta(R) - \Delta(R\cup\{a^*\})$ — a single off-closure axis gives the exact identity; $k\ge2$ gives a partial bound (predicting the empirical “raw VoI ties”).

Honest open checkpoints

Three checkpoints remain for a human theory pass — and crucially, none blocks C1–C3:

  • (G3) form-regularity of the structural assumption
  • $\mathrm{Bind}^*$ (declared) vs $\mathrm{bind}(\theta^*)$ (active at the true optimum)
  • the monotone-discontinuous certification edge

The work is logged transparently in docs/OPEN_QUESTIONS.md and docs/theory/W7_closure_characterization.md. The empirical claims stand on significance tests and exact identities independent of these checkpoints.
