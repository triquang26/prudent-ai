# Trust or Escalate: LLM Judges with Provable Guarantees for Human Agreement

**arxiv:** 2407.18370  
**title:** Trust or Escalate: LLM Judges with Provable Guarantees for Human Agreement  
**venue:** ICLR 2025 Oral  
**authors:** Jaehun Jung, Faeze Brahman, Yejin Choi (University of Washington / Allen Institute for AI)

---

## Thesis

The paper argues that LLM-based evaluation should not naively trust a judge model's preference on every instance, but should instead _selectively_ evaluate: estimate the judge's confidence that humans would agree, and only commit to an evaluation when that confidence is sufficiently high. Under this selective framework, the paper proves that a user-specified human-agreement level (1 − α) can be provably guaranteed — with high probability (1 − δ) over calibration sets — by formulating threshold selection as a fixed-sequence multiple-hypothesis testing problem on a small held-out calibration set. The guarantee is extended to cost-efficient cascades of models (cheap → strong), where each tier is only escalated to when the cheaper tier is insufficiently confident, and the full cascade still carries the formal risk-control bound.

---

## Contributions

- **Selective evaluation framework for LLM judges.** A formal abstention policy (Eq. 1) that outputs a label only when a confidence measure c_LM(x) ≥ λ, otherwise abstains (∅). This yields a provable guarantee P(LLM agrees with human | LLM evaluates) ≥ 1 − α.

- **Threshold calibration via fixed-sequence testing (Theorem 1).** Given a small calibration set D_cal of human preferences, the threshold λ̂ is found by sweeping from high to low and stopping at the last point where the (1 − δ) upper confidence bound of the empirical risk R̂⁺(λ) is ≤ α. This provides an _exact_ conditional guarantee (not just a marginal or in-expectation bound), tighter than Bonferroni correction and unlike prior conformal methods that only control risk marginally in expectation.

- **Simulated Annotators — a novel unsupervised confidence estimator.** Rather than using predictive probability or verbalized confidence (both shown to be over-confident for preference evaluation), annotators are simulated via K-shot in-context learning with N different per-annotator example sets. Confidence = agreement ratio across N simulated annotations. Reduces Expected Calibration Error (ECE) by ~50% and improves AUROC by ~13% vs. GPT-4 predictive probability baselines.

- **Cascaded Selective Evaluation (Algorithm 1 + Algorithm 2).** A cascade M₁ (cheap) → M₂ → … → M_N (strongest): each model evaluates when sufficiently confident; otherwise escalates. Thresholds are calibrated sequentially on the sub-population that reaches each tier, using Bonferroni-style δ/|M| correction per tier to maintain the full cascade guarantee.

- **Empirical demonstration on three benchmarks:** TL;DR (summarization), ChatArena (real-world chat assistant), Auto-J (meta-evaluation). In every setting, Cascaded Selective Evaluation achieves ≥ 91% guarantee success rate while using substantially cheaper models for the majority of evaluations.

## Method

### Selective Evaluator (§2)

Given an LLM judge f_LM : X → Y and a confidence measure c_LM : X → [0,1], the selective evaluator is:

```
(f_LM, c_LM)(x) = f_LM(x)  if c_LM(x) ≥ λ
                  ∅           otherwise
```

The **key insight**: threshold λ trades precision (human agreement rate on evaluated instances) against coverage (fraction of instances evaluated rather than abstained). By calibrating λ on held-out data, the framework converts this trade-off into a formal guarantee.

### Human Agreement Guarantee — Fixed-Sequence Testing (§2.1)

Given a calibration set D_cal of size n with human labels y_human, the empirical risk at threshold λ is:

```
R̂(λ) = (1 / n(λ)) * Σ 1{f_LM(x) ≠ y_human ∧ c_LM(x) ≥ λ}
```

where n(λ) = number of instances with c_LM(x) ≥ λ. Because n(λ)·R̂(λ) ~ Binomial(n(λ), R(λ)), the exact (1−δ) upper confidence bound R̂⁺(λ) is computed analytically. Sweeping λ from large to small, λ̂ is set to the smallest λ such that R̂⁺(λ') ≤ α for all λ' ≥ λ (fixed-sequence testing, Bauer 1991). This λ̂ yields:

**Theorem 1:** P(f_LM(x) = y_human | c_LM(x) ≥ λ̂) ≥ 1−α, with probability ≥ 1−δ.

The guarantee is _conditional_ on the calibration draw and holds for every individual run, not just in expectation over many calibration resamples — a strictly stronger claim than most prior conformal LLM work.

### Simulated Annotators (§2.2)

Existing confidence measures (predictive probability, verbalized confidence) are over-confident even for GPT-4, because a model can be accurate against a single annotator yet disagreed with by the majority. The authors simulate N annotators by K-shot prompting the judge N times with different per-annotator example sets (x_{i,j}, y_{i,j}), then define:

```
c_LM(x) = max_y  (1/N) Σ_j p_LM(y | x; K-shot from annotator j)
f_LM(x) = argmax_y Σ_j p_LM(y | x; K-shot from annotator j)
```

When N simulated annotators disagree, confidence is low; when they agree, confidence is high. This is unsupervised (no new training or supervision), and models calibration across diverse human preferences, not just model self-consistency.

### Cascaded Selective Evaluation (§2.3, Algorithm 1 & 2)

A list of models M = (M₁, …, M_{|M|}) ordered cheapest to strongest:

1. For each test instance x, start with M₁.
2. If c_{M_i}(x) ≥ λᵢ: output f_{M_i}(x) and stop.
3. Otherwise escalate to M_{i+1}.
4. If all models abstain: output ∅.

**Calibration (Algorithm 2):** Thresholds are calibrated sequentially. For M₁, calibrate on the full D_cal with risk δ/|M|. For M₂, calibrate only on the D_cal sub-population not handled by M₁ (instances with c_{M₁}(x) < λ₁), again with risk δ/|M|. Union bound over |M| tiers guarantees P(R_cascades > α) ≤ δ for the full cascade.

## Key Results

### Calibration (Table 1)

Simulated Annotators (Ind., K=N=5) vs. baselines on AlpacaEval and TL;DR:

| Judge | Baseline ECE | Simulated Ann. ECE | Baseline AUROC | Simulated Ann. AUROC |
|---|---|---|---|---|
| GPT-4-turbo | 0.215 (Pred.Prob.) | **0.039** | 0.548 | **0.755** |
| GPT-3.5-turbo | 0.293 | **0.058** | 0.581 | **0.632** |
| Mistral-7B | 0.374 | **0.075** | 0.457 | **0.632** |

ECE reduced by ~50% across all judge models; Simulated Annotators even makes weaker judges' confidence estimates competitive.

### TL;DR Summarization (Figure 3, Table 2)

- Target agreement 1−α = 0.90: Cascaded Selective Evaluation achieves empirical agreement ≥ 0.90 in >90% of runs (guarantee success rate), vs. GPT-4 without abstention achieving only ~72.4% agreement with no guarantee.
- At target 1−α = 0.90 with 43.5% coverage: 55.7% of evaluated instances are handled by Mistral-7B or GPT-3.5, with GPT-4 used for only 28.3%.

### ChatArena (Figure 4, Table 3)

- At target 1−α = 0.85: Cascaded Selective Evaluation achieves 91.0% guarantee success rate with 63.2% coverage.
- 88.1% of evaluated instances handled by Mistral-7B (31.7%) + GPT-3.5 (37.97%), with GPT-4 used for only 11.9%.
- GPT-4 without abstention achieves only 78.5% human agreement and 0% guarantee success rate at 1−α = 0.85.

### ChatArena with only weak cascade (Table 6, 1−α = 0.80)

- Weaker cascades (Mistral-7B → Mixtral-8×7B → GPT-3.5; no GPT-4): 80.3% empirical agreement, 68.3% coverage, 90.8% guarantee success rate, at only **12.6% of GPT-4 API cost**.
- Stronger cascades (Mistral-7B → GPT-3.5 → GPT-4): 80.2% agreement, 77.6% coverage, 90.5% success rate, at 21.5% of GPT-4 cost.

### Auto-J (Figure 5, Table 8)

- GPT-4 without abstention achieves only 63.2% human agreement. Cascaded Selective Evaluation guarantees up to 80% human agreement with high probability.

### Abstention Alignment with Human Subjectivity (Table 4)

- Abstained samples: IAA = 0.815 (σ=0.031). Evaluated samples: IAA = 0.902 (σ=0.025). Difference is statistically significant (p < 1e-8).
- Length ratio and token overlap differences between abstained and evaluated are NOT significant (p > 0.10), confirming the policy is not exploiting superficial features.

### Robustness to Distribution Shift (Table 9)

- Even with train/test model-population split, guarantee success rate remains ≥ 90.7% across all target α values (70–90%), with only modest coverage reduction.

## Relevance to APT

This paper is the **primary model paper for APT's C3 claim** — the method core of the research agenda. It provides concrete prior art, formal machinery, and empirical validation patterns for each element of C3: *selective 3-state procedure + VoI-guided acquisition + coverage guarantee*.

### Direct mapping to C3 components

**Selective 3-state procedure.** The APT P0 formalism (§6, §9) defines a 3-state output: `{commit_cheap, commit_safe, abstain}`. Trust-or-Escalate implements the analogous 3-state: `{evaluate_M1, evaluate_MN, abstain}`. The abstention state in Trust-or-Escalate is not "I don't know" but "the confidence estimate doesn't clear the threshold calibrated to guarantee 1−α agreement" — exactly the APT principle of "only commit when the evidence regime justifies it." The paper's abstention policy aligning with human-perceived subjectivity (Table 4) is the empirical analogue of APT's claim that abstention reveals *informative structure* (not random noise).

**Coverage guarantee.** Trust-or-Escalate's core technical result — P(LLM agrees with human | LLM evaluates) ≥ 1−α with probability ≥ 1−δ — is the template for APT's coverage guarantee (APT P0 §9): calibrate on ground-truth slice, report coverage–risk curve. The APT MASTER plan explicitly cites this paper for the guarantee pattern and coverage-at-agreement reporting convention. APT's extension is that the "object" being decided is a *multi-constraint deployment decision under structured missingness* (feasibility ∧ min-sufficiency jointly), which is strictly harder than binary preference classification, and the guarantee is indexed by *evidence regime*, not sample size — this "delta novelty" (APT §9) is what APT must articulate to avoid being a straight port.

**Cost-aware cascade (VoI proxy).** Trust-or-Escalate's cascaded escalation (cheap model first, escalate only when not confident) is a concrete implementation of the VoI-guided acquisition cascade in APT §7–§9: rank axes by `VoI(f)/cost(measure f)` and acquire cheap axes first. In Trust-or-Escalate the "axes" are judge model tiers rather than evidence fields, but the principle — pay for stronger evidence only when cheap evidence is insufficient — is identical. APT's VoI formalism (§7) maps to the confidence threshold calibration procedure in Trust-or-Escalate; both decide *when to escalate/acquire* to minimize expected regret at bounded cost.

### APT phases informed

- **P0 (formalism):** The fixed-sequence testing proof (Theorem 1, Appendix A.1) and cascade extension (Algorithm 2, Appendix A.2) are the formal backbone for APT §9's guarantee. The Bonferroni-based δ/|M| budget split over cascade tiers is directly usable in the APT multi-axis VoI cascade.

- **P1 (interface kit):** The `certify_*(x, c, α)` stub in APT's three-state classifier interface (P0 §10 schema) mirrors Trust-or-Escalate's selective evaluator signature: input = (instance, confidence measure, risk tolerance), output = label or ∅. Trust-or-Escalate's prompt design (Simulated Annotators, few-shot per-annotator examples) informs what P1 must expose at the confidence-estimation interface.

- **P4 (selective procedure + guarantee + VoI):** The most direct tie. Trust-or-Escalate is the existence proof that the APT P4 procedure is implementable. APT P4 must implement: 3-state feasibility + chance-constrained + coverage guarantee (calibrate on slice) + VoI ranking + Pareto-under-uncertainty. Trust-or-Escalate demonstrates items 1 and 3 (3-state + guarantee) with working code; APT extends to items 2, 4, 5 (chance-constrained feasibility, VoI as regret-reduction, Pareto under evidence uncertainty).

- **P5 (validation):** Trust-or-Escalate's V2-equivalent validation (coverage–risk curve, guarantee success rate over 1000 random splits, comparison against point-estimate calibration baselines) is the reporting template APT must replicate: coverage–risk curve, guarantee holds at coverage high, baseline rules violate guarantee, VoI field predicts regret reduction.

### Key distinction: APT's delta novelty over Trust-or-Escalate

APT must not be a straight port. The APT MASTER plan flags two distinctions:
1. APT's "object" is a multi-constraint deployment decision under *structured missingness* (not binary preference). `feasible ∧ minimum-sufficient` jointly, where some axes are structurally missing (not randomly absent).
2. APT's guarantee is indexed by *evidence regime* R, not by sample size. The irreducible regret–coverage tradeoff theorem (APT §8.6) proves that a regime-restricted rule *cannot* achieve both full coverage and zero regret, so abstention is *provably necessary* — a stronger claim than Trust-or-Escalate's empirical demonstration that abstention improves agreement.

## Key Quotes

1. **Core guarantee (§1, p.1):**
   > "given a user-defined risk level α, we provide a guarantee that, for an unseen instance x, P(LLM preference on x agrees with human | LLM evaluates x) ≥ 1 − α."

2. **Motivation for selective evaluation (§1, p.1):**
   > "a reliable evaluation framework should not only consider the preference of a model, but also the validity of the preference—i.e., how likely humans would agree with the model judgement. When a model cannot confidently evaluate a given instance, we should not rely on its evaluated result."

3. **Advantage over prior conformal methods (§2.1, p.3):**
   > "unlike prior works (Gui et al., 2024; Mohri & Hashimoto, 2023) that only controls the risk in expectation over calibration sets (solid blue line), our method guarantees with high probability that each individual run would satisfy the target agreement level (light blue region)."

4. **Over-confidence finding (§2.2, p.4):**
   > "simply achieving human-level performance may not be sufficient for reliable evaluation: while an LLM judge can be as accurate as a single human annotator, it tends to be over-confident in estimating its agreement with the majority of annotators."

5. **Abstention policy aligns with genuine subjectivity (§3.3, p.7–8):**
   > "The average inter-annotator agreement is 0.815 (σ² = 0.031) for abstained samples and 0.902 (σ² = 0.025) for evaluated samples, a statistically significant difference in two-sample t-test with p < 1e−8. [...] the instances abstained by LLM judges tend to be more subjective even for humans (with no evidence of reliance on some spurious heuristics)."

6. **Practical cost efficiency (§3.6, Table 6):**
   > "both configurations of Cascaded Selective Evaluation significantly reduce evaluation costs compared to using GPT-4, achieving savings of up to 78.5% with stronger cascades and 87.4% with weaker cascades."
