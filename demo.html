Database Architecture

7-Table Schema

Evidence flows from source → evidence_item → composition/benchmark_run. Right-sizing profiles encode deployment constraints for each pattern.

Figure 1 — Entity-Relationship diagram. FK arrows show referential constraints enforced by SQLite PRAGMA foreign_keys=ON.

TableRowsPurpose

component88Atomic AI components: LLMs, retrievers, tools, rerankers, agents
composition175Pipelines built from components; each has a pattern (RAG, web_nav, …)
composition_component0Bridge table: which components play which role in each composition

W3

Belief Representation

✅ integrated

What it proves: Evidence is stored as Belief intervals $[\ell, h]$ rather than point estimates. This supports the conformal-calibration interpretation: $\ell = \hat{q} - \tau_\alpha$ and $h = \hat{q} + \tau_\alpha$ for a chosen miscoverage rate $\alpha$. The $\bot$ (bottom) element represents a "missing" axis — a structural gap, not just a zero.

belief.py — Belief(lo, hi, is_bot), kappa_filter() for confidence tiers, phi_interval() for interval-valued feasibility checks

Figure 3 — Belief intervals capture measurement uncertainty. GPT-4o clearly exceeds the threshold; Llama-3-8B is borderline; a missing axis is ⊥ (bot), a structural gap that blocks decidability.

W5

Three-Valued Verdict

✅ integrated

What it proves: Given a query (task, quality_min, lat_max, cost_max), the engine produces a three-valued verdict rather than always picking a winner. The three outcomes are:

VerdictConditionAction
decidable ≥1 composition meets all constraints with high-confidence evidence Return ranked list; pick cheapest within 10% of top quality
underdetermined Evidence exists but intervals overlap; cannot rank with confidence Name the cheapest axis to measure to unblock the decision
infeasible No composition satisfies the constraints, no matter how measured Report binding constraints; suggest relaxing the hardest one

verdict.py exports decidable(), underdetermined(), infeasible_binding() — all computed from the Belief lattice, never from raw floats.
